# 英語学習スタンプ（raz-stamp）

Raz-Kids などの毎日の英語学習を、**月ごとのカレンダーにスタンプを押して**記録するアプリです。
Android タブレットのホーム画面にインストールして使うことを想定した PWA（Web アプリ）です。

> Raz-Kids / Learning A-Z とは関係のない非公式アプリです。Raz-Kids のアカウント情報は扱いません。

## できること

- 学習が終わったら、5種類からスタンプを選んで「学習完了！」をタップする（1人1日1回まで）
  - よんだ！（本）／きいた！（ヘッドホン）／クイズ満点（花丸）／レベルアップ（ロケット）／ネコ先生
  - 前回選んだスタンプを人ごとに覚えている。押したあとでもカレンダーの日付から変更できる
- 月ごとのカレンダーで押した日を確認し、◀ ▶ で過去の月に切り替えられる
- 押し忘れた日は、カレンダーの日付をタップすると**あとから押せる**（3日前まで。「後」マークが付く）
- **おくすり（連続記録の救済アイテム）**
  - 5日連続ごとに1個もらえる（最大2個まで持てる）。画面の「もちもの」欄と名前の横に個数を表示
  - 学習できなかった日が1日だけあるとき、おくすりを使うとその日を救済して連続記録がつながる（空いた日の翌々日まで）
  - 救済した日は連続日数には数えるが、今月の達成日数には数えない
  - 2日以上続けて空いた場合や、2日続けての使用はできない
- 間違えて押したスタンプは取り消せる（押した直後なら「元に戻す」でも取り消せる）
- 連続日数、今月の達成日数、最高連続日数を表示
- 押印履歴の一覧（押した日時、あとから押したかどうか、メモ）
- **兄弟など複数人で1台を共有できる**（画面右上で使う人を切り替え）
- バックアップファイル（JSON）の保存と復元
- オフラインでも動く

## データの保存場所

学習データは**その端末のブラウザの中（IndexedDB）だけ**に保存されます。サーバーには送信しません。
そのため、次の操作をするとデータが消えます。

- ブラウザ（Chrome）の「サイトデータの削除」をした
- アプリをアンインストールした

月に1回ほど、「設定 → バックアップを保存」でファイルを保存しておくことをおすすめします。

## Android タブレットへのインストール

1. Chrome で公開 URL（例: `https://<ユーザー名>.github.io/raz-stamp/`）を開く
2. 右上の「︙」メニュー →「アプリをインストール」（または「ホーム画面に追加」）
3. ホーム画面のアイコンから起動する

## 公開方法（配布する人向け）

ビルドは不要です。このフォルダをそのまま静的サイトとして公開すれば動きます。
PWA としてインストールするには **HTTPS** で公開する必要があります。

### GitHub Pages で公開する

1. このフォルダの中身を GitHub リポジトリにプッシュする
2. リポジトリの Settings → Pages → Branch に `main` / `/ (root)` を指定する
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

### 自分の PC で試す

```bash
python3 -m http.server 8080
```

ブラウザで http://localhost:8080 を開きます。

## 更新するときの注意

オフライン対応のため、アプリのファイルは端末にキャッシュされます。
ファイルを変更して公開し直すときは、`sw.js` の `CACHE` の番号を上げてください（例: `raz-stamp-v1` → `raz-stamp-v2`）。
上げないと、利用者の端末で古いままになります。

## 開発

| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | 画面 |
| `js/main.js` | 画面の描画と操作 |
| `js/domain.js` | 日付・連続日数・バックアップ検証などのロジック（DOM に依存しない） |
| `js/db.js` | IndexedDB への保存 |
| `js/stamps.js` | スタンプのデザイン（オリジナル SVG）。`STAMP_DESIGNS` に足せば種類を増やせる |
| `js/domain.js` の `ITEM_EVERY` / `ITEM_MAX` / `BACKFILL_DAYS` | おくすりの付与間隔・上限、あとから押せる日数 |
| `sw.js` / `manifest.webmanifest` | PWA（オフライン・インストール） |

外部ライブラリは使っていません。ロジックのテストは Node.js 18 以上で実行できます。

```bash
npm test
```
